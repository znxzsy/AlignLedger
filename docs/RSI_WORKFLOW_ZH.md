# RSI 工作流：人类反馈与数据准备

AlignLedger 向外部管理的迭代流程提供经复核记录与冻结快照，不执行训练或判断模型是否变好。

## 具体交接

- 导入：使用文档中的 `details_*.json` 导入器与稳定记录标识；VeriInk 来源数据需先编写领域适配器。
- 审核：模型输出、原始标注、二次复核和有效修正分别保留。
- 冻结：`export_snapshot(db_path, output_root)` 在时间戳目录内输出复核表、SFT 完整组、DPO/KTO 候选、manifest 和 `FROZEN_OK`。
- 校验：下游使用前核对文件哈希并审核导出策略与候选含义；完成标记不能替代语义或防泄漏审计。
- 使用：下游定义数据切分、验证训练格式，并记录快照与训练模型的对应关系；独立审核的评测不得混入训练与模型选择。

## 决策与证据

1. 审核／发现数据与评测数据分别管理，训练前定义题源或组级隔离规则；这两个仓库不负责全研究范围的防泄漏检查。
2. 保留未知和拒绝样本。模型失败可能来自练习不足、证据模糊或标签错误，不能自动推导为生成器缺少能力。
3. 合法数据能力是否保留、训练 checkpoint 是否采用，分别决定。文件哈希与软件测试通过均不能证明模型收益或真实场景迁移。
4. 固定基线、声明预算，保留负结果；在适当隔离的评测上完成比较后再考虑晋升。

## 公开边界

这是由人指导的数据工作流。两个仓库之间的自动连接、递归训练器、自主代码生成 Agent、研究验证器和模型晋升控制器均不在公开版内。下述虚构记录没有操作权限，也不是实验回执。研究核心源码、提示词、私有数据和模型权重不在这两个仓库公开。
